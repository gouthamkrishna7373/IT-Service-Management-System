# IT-Service-Management-System
A web-based IT services management portal for managing support tickets, service requests, IT assets, clients, and reports.
  🚀 ITServicePro – IT Services Management Portal

# Project Overview
ITServicePro is a web-based IT Services Management Portal designed to simplify and organize IT support activities within an organization.
The system provides a centralized platform for managing support tickets, service requests, IT assets, clients, and technical knowledge. It helps administrators monitor IT operations through an interactive dashboard and generate reports for better decision-making.

#  Objectives
- Simplify IT support ticket management.
- Provide a centralized service catalog.
- Manage IT service requests efficiently.
- Maintain IT asset records.
- Store and manage client information.
- Provide solutions to common IT problems.
- Generate reports and export ticket data as CSV.
- Offer a modern, responsive user interface.

# ✨ Features
 1.  Dashboard
- Display total tickets.
- Track open tickets.
- Monitor resolved tickets.
- Display total registered assets.
- View recent support tickets.
 2.  Service Catalog
- Hardware Support
- Network Support
- Security Support
- Software Support
3. Ticket Management
- Create new support tickets.
- Search existing tickets.
- View ticket priority and status.
- Assign tickets to the IT support team.
- Resolve tickets.
- Delete tickets.
 4.  Service Requests
- Submit new IT service requests.
- Select the type of service required.
- View previously submitted requests.
- Track request details.
 5. Asset Management
- Register IT assets.
- Store asset names and types.
- Maintain serial numbers.
- Assign assets to users.
- View registered assets.
- Delete asset records.
 6.  Client Management
- Register new clients.
- Store client names, email addresses, and phone numbers.
- View registered clients.
- Delete client records.
7.  Knowledge Base
- Find solutions to common IT problems.
- Troubleshoot internet connectivity issues.
- Get guidance on password resets.
- Access basic computer troubleshooting information.
 8. Reports & Analytics
- View ticket statistics.
- Monitor open and resolved tickets.
- View total registered assets.
- Export ticket information as a CSV file.
9. User Interface
- Modern dashboard design.
- Dark mode interface.
- Sidebar navigation.
- Interactive buttons and forms.
- Organized tables and information cards.
